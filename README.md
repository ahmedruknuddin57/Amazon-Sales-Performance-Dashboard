# 📊 Amazon Sales Performance Dashboard

## Overview

This Power BI dashboard provides an executive overview of Amazon sales performance using interactive visualizations, KPI cards, DAX measures, and dimensional modeling.

![Amazon Sales Performance Dashboard](Amazon%20dashboard%20image.jpg)

## Business Problem

This dashboard helps business stakeholders monitor:

- Sales performance
- Customer insights
- Product performance
- Geographic performance
- Monthly sales trends

---

## KPIs

- Total Sales
- Total Orders
- Total Customers
- Average Order Value
- Average Discount
- Total Tax

## Visualizations

- Monthly Sales Trend
- Sales by Category
